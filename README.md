 Bookstore in  mvc .net core
--------------------------------
There are 2 roles in this project:

Admin:

The admin can delete, activate, or deactivate users.
The admin can add authors and view their details.
The admin can add genres and view their details.
The admin can add books and view their details.
The admin can view user orders and confirm orders.
The admin can view contact details.
The admin can update their own profile.
User :

The user can register and log in.
The user can view book details.
The user can add books to the cart and add them to the wishlist.
The user can fill out the contact us form.
The user can view their orders.
